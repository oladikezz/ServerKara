# AurionKara

Плагин для Minecraft-серверов на **Leaf/Paper 1.21.11**, добавляющий систему штрафов, вызовы гвардии и удобное меню управления.

## Возможности

- Выдача штрафов игрокам.
- Настраиваемые сумма, срок и причина штрафа.
- Уведомления о штрафах при входе.
- Уведомления о просроченных платежах.
- Общий список штрафов и должников.
- Вызов гвардии командой `/911`.
- Передача гвардейцам сообщения, мира и координат вызова.
- Телепортация к месту происшествия через меню.
- Отображение состава гвардии и онлайн-статусов.
- Заявки на вступление в гвардию.
- Возможность назначить нескольких главных гвардейцев.
- Хранение данных без подключения отдельной базы данных.
- Не требует Vault или других обязательных зависимостей.

## Команды

| Команда | Описание |
|---|---|
| `/kara <игрок> <сумма> <время> <причина>` | Выдать штраф |
| `/kara list` | Посмотреть собственные штрафы |
| `/kara list <игрок>` | Посмотреть штрафы игрока |
| `/kara paid <ID>` | Отметить штраф оплаченным |
| `/911 <описание>` | Вызвать гвардию |
| `/karamenu` | Открыть меню гвардии |
| `/guard apply` | Подать заявку в гвардию |
| `/guard add <игрок>` | Принять игрока в гвардию |
| `/guard remove <игрок>` | Исключить гвардейца |
| `/guard setchief <игрок>` | Добавить главного гвардейца |
| `/guard removechief <игрок>` | Снять главного гвардейца |
| `/guard list` | Посмотреть состав гвардии |

Пример выдачи штрафа:

```text
/kara Steve 500 2d Нарушение общественного порядка
```

Поддерживаемые обозначения времени:

- `30m` — 30 минут
- `2h` — 2 часа
- `3d` — 3 дня
- `1w` — 1 неделя
- `1d12h` — 1 день и 12 часов

## Меню гвардии

Меню открывается командой `/karamenu` и содержит следующие разделы:

- Активные вызовы.
- Должники.
- Все штрафы.
- Состав гвардии.
- Заявки на вступление.

Управление вызовами:

- ЛКМ — телепортироваться к месту вызова.
- ПКМ — закрыть вызов.

Управление штрафами:

- `Shift + ПКМ` — отметить штраф оплаченным.

Управление составом:

- ЛКМ по заявке — принять игрока.
- ПКМ по заявке — отклонить заявку.
- `Shift + ПКМ` по гвардейцу — исключить его.

## Главные гвардейцы

Несколько руководителей можно указать в `config.yml`:

```yaml
chief-guards:
  names:
    - "Fasar"
    - "oladik"
  uuids: []
```

## Права

```text
aurionkara.guard
aurionkara.fine.issue
aurionkara.fine.manage
aurionkara.chief
aurionkara.admin
```

Право `aurionkara.admin` включает полный доступ ко всем функциям плагина.

Гвардейцы, принятые через встроенную систему, получают доступ к меню без дополнительной настройки LuckPerms.

## Установка

1. Установите Java 21.
2. Скачайте `AurionKara-1.1.0.jar`.
3. Поместите файл в папку `plugins` сервера.
4. Перезапустите сервер.
5. Настройте главных гвардейцев в `plugins/AurionKara/config.yml`.

## Совместимость

- Minecraft 1.21.11
- Paper 1.21.11
- Leaf 1.21.11
- Java 21

## Хранение данных

Штрафы, вызовы, заявки и состав гвардии сохраняются в файле:

```text
plugins/AurionKara/data.yml
```

Не рекомендуется редактировать этот файл во время работы сервера.

## Сборка

```text
gradle build
```

Собранный плагин появится в папке:

```text
build/libs
```

## Лицензия

Проект предназначен для использования и доработки владельцами Minecraft-серверов.
