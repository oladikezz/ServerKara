# AurionKara

Плагин штрафов и гвардии для **Leaf/Paper 1.21.11**, Java 21.

## Установка

1. Поместите `AurionKara-1.1.0.jar` в папку `plugins` сервера.
2. Перезапустите сервер.
3. Откройте `plugins/AurionKara/config.yml`.
4. В `chief-guards.names` укажите ники главных гвардейцев. При желании также
   добавьте их UUID в `chief-guards.uuids`.
5. Перезапустите сервер или назначьте главного гвардейца из консоли:
   `guard setchief Ник`.

Данные штрафов, вызовов, состава и заявок автоматически сохраняются в
`plugins/AurionKara/data.yml`.

## Команды

- `/kara <игрок> <сумма> <время> <причина>` — выдать штраф.
- `/kara list` — посмотреть собственные штрафы.
- `/kara list <игрок>` — открыть штрафы указанного игрока (для гвардии).
- `/kara paid <id>` — отметить штраф оплаченным.
- `/911 <описание>` — вызвать гвардию с передачей мира и координат.
- `/karamenu` — открыть меню гвардии.
- `/guard apply` — подать заявку в гвардию.
- `/guard add <ник>` — принять игрока вручную.
- `/guard remove <ник>` — исключить гвардейца.
- `/guard setchief <ник>` — добавить главного гвардейца.
- `/guard removechief <ник>` — снять главного гвардейца.
- `/guard list` — показать состав и онлайн-статусы.

Формат времени: `30m`, `2h`, `3d`, `1w`, можно комбинировать: `1d12h`.

## Меню

- **Вызовы**: ЛКМ — телепортироваться, ПКМ — закрыть вызов.
- **Должники**: сумма долга, число штрафов, ближайший срок и просрочки.
- **Все штрафы**: Shift + ПКМ — отметить активный штраф оплаченным.
- **Состав**: онлайн-статусы; главный гвардеец принимает/отклоняет заявки
  и исключает гвардейцев через Shift + ПКМ.

## Права

- `aurionkara.guard`
- `aurionkara.fine.issue`
- `aurionkara.fine.manage`
- `aurionkara.chief`
- `aurionkara.admin` — включает все права выше.

Гвардейцы, принятые через плагин, получают доступ к меню без настройки
плагина прав. Операторы сервера имеют все права по умолчанию.

## Сборка

Проект собирается на Java 21:

```text
gradle build
```

Готовый файл появится в `build/libs`.
