ServerKara — это многофункциональный Role-Play плагин для Minecraft-серверов на базе **Leaf/Paper 1.21.11**. Он добавляет систему выписки штрафов, вызовы экстренной помощи (`/911`) и удобное графическое меню (GUI) для управления работой гвардии.

## ✨ Основные возможности

- 💸 **Система штрафов:** Выдавайте игрокам штрафы с указанием суммы, причины и крайнего срока оплаты (с уведомлениями о просрочке).
- 🚨 **Вызов гвардии:** Игроки могут использовать команду `/911 <сообщение>` для экстренного вызова. Гвардейцы мгновенно получают координаты и мир.
- 📱 **Интерактивное меню:** Команда `/karamenu` открывает GUI для просмотра активных вызовов, списка должников, состава гвардии и заявок на вступление.
- ⚡ **Быстрые действия:** Телепорт к месту вызова по левому клику в меню, и пометка штрафа оплаченным через `Shift + ПКМ`.
- 👮 **Система заявок:** Игроки могут подать заявку (`/guard apply`), а главные гвардейцы — принять или отклонить её прямо в меню без необходимости настраивать LuckPerms!
- 📂 **Простота и автономность:** Все данные надежно хранятся в YAML. Никаких обязательных зависимостей вроде Vault или сторонних баз данных.

## 💻 Команды

| Команда | Описание |
|---|---|
| `/kara <игрок> <сумма> <время> <причина>` | Выписать штраф |
| `/kara list [игрок]` | Посмотреть свои штрафы (или штрафы другого игрока) |
| `/kara paid <ID>` | Отметить штраф оплаченным |
| `/911 <описание>` | Экстренно вызвать гвардию |
| `/karamenu` | Открыть панель управления гвардией (GUI) |
| `/guard apply` | Подать заявку на вступление в ряды гвардии |
| `/guard add/remove <игрок>` | Принять/Исключить гвардейца |
| `/guard setchief/removechief <игрок>` | Назначить/Снять главного гвардейца |

*Примеры формата времени: `30m` (минуты), `2h` (часы), `3d` (дни), `1w` (недели), `1d12h`.*

## 🚀 Установка

1. Убедитесь, что установлен **Java 21** и **Paper/Leaf 1.21.11**.
2. Закиньте готовый `AurionKara.jar` в папку `plugins`.
3. Перезапустите сервер.
4. Назначьте главных гвардейцев в файле конфигурации: `plugins/AurionKara/config.yml`.

## 🛠️ Сборка из исходников
```bash
gradle build
```
Скомпилированный `.jar` файл плагина появится в папке `build/libs`.
